# 兼容性与验证范围

当前目标是 **杂交重制版 0.31.0 Windows x64 C# 构建**，插件版本 **0.5.16**。目标 `PlantsVsZombies.dll` SHA256：

```text
820E9E8F91F58062FCFC7548BDB9E5588EC8F822F5DDC71F4B4D83B09A912D95
```

其他引擎版、原版 PvZ、恐怖版和游戏新版不自动兼容。游戏程序集受裁剪影响，仅相同 API 名称并不能证明实际运行库兼容。安装器校验目标哈希，桥接初始化核对游戏版本。

本次独立项目整理保留现有 C# 原生动作源码与编译包，主要增加玩家安装、隔离存档路径、公共文档及发布工具。定向离线验证覆盖配置生成、MCP 握手、发布排除规则、原目录不写入、重复安装保留存档、运行目标拒绝替换及不兼容构建拒绝复制。它不启动真实游戏，不代表新的通关验收。

开发历史已覆盖普通关卡逐次种植、事件与回执关联、正常扣费/冷却、拾取、领奖返回、释放控制、部分扩展工具和 0.5.16 每日挑战日历导航。相关功能记录见本目录的契约文档；历史证据文件未随公开仓库分发。不能据此推断所有卡牌、地形、特殊关卡或模型策略都已实机验证。

`verify_*_live.py` 是会实际操作游戏的专用验收夹具，不在普通测试或安装自检中执行。首次安装需玩家启用插件、重新加载并创建玩家档案；是否成功接入以本次游戏的 capabilities 和现场为准。
